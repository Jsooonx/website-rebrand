# Vesper Studio

Portfolio Jay-inspired rebrand with an original Vesper hero, data-driven Experience accordion, a four-project WorkStack, an interactive Services panel, an editorial About gallery, a compact local Logo Cloud, a three-reviewer Testimonial carousel, a data-driven Pricing section, a five-item FAQ accordion, and a responsive contact footer. WorkStack uses locally generated artwork and CSS sticky stacking on desktop, while the About gallery advances one complete visual tile at a time, supports arrows and touch swipes, and becomes static when reduced motion is requested. Testimonial navigation is manual and uses locally generated reviewer portraits. Pricing switches between Monthly and Per Project engagement models without a page reload. FAQ items use a single-open disclosure model and can also be fully collapsed. The footer reuses the local founder portrait and provides a centered booking CTA with accessible social links.

## Run

```bash
npm install
npm run dev
```

The implementation uses Vite, React, TypeScript, Framer Motion, and Lenis. The hero is designed around the supplied desktop reference composition; no Framer export files are used or modified.
