# PHASE

PHASE is a fictional independent creative-production studio website for
brands making their next move. The experience is an original rebrand developed
from supplied visual references, not a reconstruction of their identity,
content, or assets.

## Stack

- Vite + React + TypeScript
- Tailwind CSS
- Framer Motion
- Lenis smooth scrolling

## Notable interactions

- Staggered, word-level editorial text reveals
- Sticky selected-work rail with four original case studies
- Custom SVG partner-mark marquee
- User-controlled testimonial transitions
- Image-led closing marquee and desktop footer reveal
- Complete `prefers-reduced-motion`, keyboard, touch, and mobile fallbacks

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Original assets and reference credit

All names, people, partners, projects, copy, generated photography, and vector
marks are fictional and original to this exploration. Production images were
generated for PHASE with OpenAI ImageGen; source PNGs are retained in
`assets/source/`, with optimized runtime derivatives in `public/images/`.
The PHASE monogram is an original AI-generated geometric mark, prepared as a
transparent header asset and a high-contrast browser icon.

The supplied FUEL references are credited as visual direction only and remain
in `references/`. No reference brand assets or distinctive content are used in
the live implementation.
