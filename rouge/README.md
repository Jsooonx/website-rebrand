# ROUGE

Original editorial art-direction studio website based on the visual principles
documented in [`DESIGN.md`](./DESIGN.md). All identity, copy, project names,
imagery, and implementation are original.

## Stack

- Vite
- React + TypeScript
- Tailwind CSS
- Framer Motion
- Lenis

## Commands

```bash
npm install
npm run dev
npm run build
```

The implementation includes reduced-motion fallbacks, a mobile project list,
manual testimonial controls, and a desktop-only sticky footer reveal.
