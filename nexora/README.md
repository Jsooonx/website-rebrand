# Nexora

Nexora is an original Stackframe demonstration template for a fictional AI
workspace. It illustrates one operational dossier: a work request gathers
connected context, reaches a verifiable decision, and becomes an accountable
next action.

Every organisation, person, scenario, outcome, operating path, integration,
and product detail shown here is fictional. Nexora is not an available product
or customer case study.

## Stack

- Vite
- React and TypeScript
- Tailwind CSS
- Motion for React
- Lenis
- Vitest and Testing Library

## Run locally

```bash
npm install
npm run dev
```

The development server opens at the URL printed by Vite. Use these commands
for validation:

```bash
npm test -- --run
npm run build
```

## Template direction

This project uses `Rework mode` because the supplied reference was a paid
template and the finished site is intended as a public Stackframe example.
Reference screenshots were reviewed section by section, saved in
[`references`](./references), and documented in [`DESIGN.md`](./DESIGN.md)
before implementation. They are design context, not source material.

The site is organised as an Operational Dossier:

- A live case file introduces the request, sources, conclusion, and owner.
- Collect, Validate, and Act show how one case progresses through the system.
- Scenario snapshots, a systems index, adoption paths, field notes, and
  fictional workflow stories explain the concept without customer claims.
- The closing launch panel resolves the demonstration case and repeats its
  fictional status in context.

## Reference boundaries

The supplied paid-template screenshots remain in
[`references`](./references) solely as private quality context. A paid-template
purchase does not by itself grant permission to redistribute a derivative
template. Nexora uses original brand content, product records, UI structure,
assets, and visual motifs so it can serve as a public Stackframe rework
example.

The complete design rationale, responsive behaviour, motion rules, and
anti-reference constraints live in [`DESIGN.md`](./DESIGN.md).
